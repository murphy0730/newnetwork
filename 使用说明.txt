供应网络控制塔 —— 快速使用说明
========================================

一、环境要求
  - Windows 电脑
  - 安装 Node.js 24 或更高版本（官网 https://nodejs.org 下载 LTS 版即可，
    安装时保持默认选项，装完重新打开窗口生效）
  - 无需联网、无需安装任何其他依赖，全部组件已随包附带

二、启动与停止
  1. 解压本压缩包到任意目录（路径不要含特殊字符）
  2. 双击 start.cmd，看到服务启动提示后保持窗口开着
  3. 浏览器访问 http://127.0.0.1:8787
  4. 停止服务：双击 end.cmd（或直接关掉启动窗口）

三、演示数据与替换为真实数据
  本包已内置一套演示数据，启动后打开网页即可直接浏览全部功能。
  import 文件夹里也放了一份演示表格，可用于演示导入流程。

  需要换成真实数据时：
  1. 把 import 文件夹里的演示表格移走或删除，放入真实业务表格
     （Excel / CSV，可多文件多工作表）
  2. 打开网页的「数据管理」，点击「扫描 import 文件夹并计算」
  3. 表头须与网页里「下载Excel模板」一致，模板内有「填写说明」工作表
  4. 多张表作为同一批次校验；校验失败不会改动现有数据，页面会列出错误清单
  5. 大文件计算需要几分钟，期间页面可继续浏览

  如需彻底清空重来：停止服务后删除 data 目录下的全部内容，再启动即为空白系统。

四、常见问题
  - 端口被占用：start.cmd 9000 换端口启动，访问 http://127.0.0.1:9000
  - 提示找不到 Node.js：说明未安装或未生效，重装 Node.js 24+ 后重新打开窗口
  - 数据文件保存在 data 目录，删除 data 目录即可清空全部已导入数据

五、技术支持
  使用中遇到报错，请把启动窗口里的错误信息截图发给开发人员。
