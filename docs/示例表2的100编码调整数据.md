# 示例表2：100个编码的供应添加与使用剔除

现有完整示例保持1004个编码、12个产业、58个加工地、最多7层BOM。从中选择100个不同编码生成表2，不缩小或替换原BOM结构。

## 层级分布

按BOM中从根节点到编码的最长路径深度划分，每个编码只计入一层；存在跨层引用时，不按编码前缀或最短路径重复计数。

| BOM层级 | 表2涉及编码数 |
| --- | ---: |
| 第1层（顶层） | 15 |
| 第2层 | 15 |
| 第3层 | 14 |
| 第4层 | 14 |
| 第5层 | 14 |
| 第6层 | 14 |
| 第7层 | 14 |
| 合计 | 100 |

每层按编码排序后等间隔选取。相同BOM和月份下可重复生成一致的数据。

## 数量规则

- 覆盖示例全部11个月，每个编码每月各一条“供应”和“使用”，共2200行。
- 供应添加取该编码当月各加工地预测合计的约5%～15%，四舍五入，至少1；采购编码为`BUY-项目编码`。
- 使用剔除取当月预测合计的约3%～8%，四舍五入，至少1且不超过预测合计；采购编码留空。
- 比例随编码、月份变化。表1保留原预测，添加和剔除只写入表2，不重复预处理。
- “加载示例”自动使用原始预测模式：净供应=表1预测+供应添加；向下层折算的净需求预测=表1预测−使用剔除。

## 查看方式与验证

启动服务，在数据管理点击“加载示例”。会生成新的示例快照，旧快照保留；已有快照不会因更新代码而自动改变。供应汇总表中选中这100个编码之一，即可查看两个调整字段。

“下载完整示例Excel”也包含2200行表2；独立模板仍保留3条填写样例。Excel不携带系统配置，如将下载的示例作为业务数据重新导入，需使用“原始预测＋表2预处理”口径。

回归覆盖100个唯一编码、各层数量、11个月的双向调整、剔除上限、Excel导出后读取、快照保存后重新装载，以及直接父子/跨产业/最顶层三种口径的汇总表取值。相关8项测试通过。
