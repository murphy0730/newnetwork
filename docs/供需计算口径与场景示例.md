## 一、先确定有效BOM

项目模板仅取表3的父项模板、子项模板，按编码汇总全表所有出现位置：

| 同编码模板情况 | 处理 |
|---|---|
| 全部一致为AI | 参与BOM关系 |
| 全部一致且明确非AI，例如POC | 该编码相关边不参与 |
| 存在空值，或同编码模板不一致 | 保留该编码，输出缺失/冲突提示，不阻止导入 |

关系的两端都保留时才参与计算；不跨非AI编码重连上下游。原始BOM保留，原始行数可能大于有效边数。模板冲突按全表判断，不取最后一行覆盖，不受文件或行顺序影响。详见[BOM项目模板范围与异常规则](BOM项目模板范围与异常规则.md)。

本文所有“父项”“根节点”均指有效BOM。有效根可能与原始BOM不同。其他表中仍存在的非AI编码可以作为独立编码展示，但不恢复其已排除的关系。

## 二、记录、部门与完整性

| 维度 | 规则 |
|---|---|
| 预测记录 | 按所选预测版本＋月份判断。有qty=0的记录是已知0；没有记录是未知，不用其他月、其他版本的记录补成显式0 |
| 表6维护行 | 有行且make_dept有值时用原部门；无行或make_dept为空时归为“未知部门” |
| 未知部门 | 所有未知部门编码属于同一个产业；与其他已知部门不同 |
| 透传 | 自身当月没有预测，且当前口径折算上游需求严格大于0。保留节点，可搜索，自身不计缺口，不计不完整KPI；有维护部门就显示原部门 |
| 供应补0 | forecast模式、版本覆盖内、自身无预测且不是透传时，自身供应按供应添加量计，原预测按0展示。这不等于其作为上游来源时拥有显式0记录 |
| 部分缺失 | cross/top同时有已知和未知来源时，按已知部分计算；已知部分可以是0。供应本身未知或透传时不据此计算缺口 |
| 全部未知 | cross/top所有来源都无当月记录时，需求和缺口未知，不按0认定富余 |
| 库存未知 | 不影响不含库存的供需完整性；库存后结果单独显示未知 |

导入后的记录范围也影响结果：BOM不再按表1、表6筛除，但表1和表4仍按“表1编码∩表6维护行”过滤；表6为空时跳过此范围过滤。make_dept为空的维护行属于已维护，编码仍可保留。没有表6维护行且预测被过滤的编码，虽然仍可在BOM中出现，也已不能提供该预测值，见S33。

## 三、三种口径与数值公式

| 口径 | 找来源 | 无记录时 |
|---|---|---|
| direct | 固定直接父项 | 按已知0计算，不上溯 |
| cross | 始终以目标编码的产业为参照；同产业继续上溯；不同产业且当月有预测记录时停止；每条路径未停止则到有效根 | 无预测的中间编码继续上溯；根保留为来源，其预测未知。根与目标同产业也保留 |
| top | 只取有效BOM根 | 根预测未知则该来源未知 |

来源数量＝绝对值（来源净需求）×路径配比乘积。同一来源多条路径汇合时，系数相加；不再叠加中间节点自身预测。缺失边界后路径回到目标产业，仍以原目标产业判断，见S21。

- raw模式：净供应＝表1预测＋供应添加；来源净需求＝表1预测－使用剔除。
- net模式：表1已预处理，表2调整不重复应用。
- 内部缺口＝上层需求＋本编码使用剔除－净供应，正数不足、负数富余。
- 内部库存后缺口＝内部缺口－库存。
- 页面与Excel供需结余＝－内部缺口；库存后结余＝－内部缺口＋库存，负数缺口、正数富余。
- 未完工指令模式使用有效未完工指令作为供应，需求仍取预测；指令表完全缺失时供应未知，不补成已知0。

有效BOM无父项时没有上层需求：图内部需求为0、缺口不适用；汇总表将来源、需求显示为“—”，两种结余为0。供应与库存仍展示。该展示差异不代表该编码有上游缺口。

## 四、单独月份、累计月份、来源及库存

- 单独月份按连续自然月分别计算，不结转前月余额。只有所选首月启用库存对比，后续月inventoryIncluded=false，库存及库存后缺口为null，表示不适用。
- 累计月份把各月供需相加，库存只计起始月一次；含不可计算月份时合计缺口未知。每月按已知部分可计算时允许相加，同时保留部分缺失标记。
- 每个月独立找来源，targets为所选期间来源并集。当月不是来源时active=false、coeff=0、贡献为0；这与有效来源缺失预测时贡献null不同。
- 月度路径系数取targets[].monthly[].coeff；若同一来源在有效月份的系数变化，顶层coeff=null，页面和导出列出逐月系数。
- 单独/累计结果读取periods；顶层兼容字段保留期间合计，不能当作首月值。KPI与风险筛选始终按所选首月，且与该月行结果一致。
- 版本覆盖内无来源记录，direct按0；cross/top继续找来源，最终根缺失则未知。版本覆盖外所有供需量未知，保留月份，不跳过、不补0。
- 库存按全表不晚于北京时间今天的最新日期选一版；不要求快照日期属于分析月份。当日无版则回退到已有最新日期。
- 已选全局快照中无该编码记录时库存0；完全无可用日期则库存未知。负库存按减法计入；备件、生产-三品子库不计入有效库存。
- 跨北京时间零点后，下一次查询更新已载入快照的日期并刷新行、KPI和筛选缓存。应用不主动拉取外部表；新库存数据仍需导入并装载。

## 六、展示、筛选、导出和升级

| 行为 | 规则 |
|---|---|
| 网络范围 | 有效BOM与其他表独立编码；聚焦取有向上游闭包∪有向下游闭包，不包含兄弟/堂兄弟 |
| 透传 | 图保留，灰色虚线；可搜索，部门依表6或未知部门规则显示；自身不计缺口 |
| 零预测 | 默认显示，可在设置中关闭；透传节点保留以免断链 |
| 独立编码 | 当前图超过100编码默认隐藏，可改设置；汇总表仍保留 |
| 箭头及配比 | 支持顶层→底层/底层→顶层；配比支持×N及1:N；100节点及以上默认隐藏配比，可手动开启 |
| 维度筛选 | 改变展示范围，不裁剪已显示供应编码的上游需求贡献，不分配缺口 |
| 汇总角色 | 供应方可用，需求方暂未开放；网络图原有角色保留 |
| 来源与导出 | 来源逐行展开；供应、总需求、缺口只在编码首行记载，避免重复求和；查询固定到页面数据版本 |
| 大表导出 | Excel按行存储单元格，避免单对象属性膨胀；报错显示失败阶段与展开行数 |
| 规则标识 | 汇总trace.relationRule为resolved-frontier-v3 |
| 升级 | 重启服务后重建、装载现有数据；旧产物算法指纹不同，不能沿用旧矩阵。无需重导原始Excel |
