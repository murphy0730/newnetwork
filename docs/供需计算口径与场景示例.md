# 供需计算口径与场景示例

> 本文全部数值示例均由当前引擎真实计算输出（非手推）。统一夹具：单月 2026-09，BOM `A→B→C`（A 顶层、C 底层），配比默认 1:1。
> 缺口公式：**缺口 = 上层需求 + 使用剔除 − 净供应**；库存后结余再减「当日最新库存快照」（表4 取不晚于今天的最新日期）。

## 一、编码状态的四个判定维度

| 维度 | 取值 | 影响 |
|---|---|---|
| 表1 预测记录 | 有记录（含数量为 0）/ 无记录 | 无记录 → 透传候选；**显式 0 ≠ 无记录**（显式 0 视为有预测，停在它） |
| 表6 维护行 | 有行 / 无行 | 无行 → 部门按「未知部门」 |
| make_dept | 有值 / 为空 | 为空 → 「未知部门」，与其他部门都不同 |
| 上游有效需求 | 有 / 无 | 无预测记录 + 上游有有效需求 → **透传节点**（passThrough） |

## 二、三种口径的「找编码」与数值规则

| | 直接父子 direct | 跨产业 cross | 最顶层 top |
|---|---|---|---|
| 需求来源 | **永远停在直接父项**（无预测按已知 0 计，不上溯、不标不完整） | 同产业上溯，停在首个不同产业编码；**边界编码无预测则跳过继续上溯** | 只取 BOM 根节点 |
| 中间层自身预测 | 直接父项有预测 → 用它的 | **不下传**（同产业只看最上层/边界） | 不下传（只看根） |
| 数值公式 | Σ 直接父项 \|净预测\| × 配比 | Σ 边界/根编码 \|净预测\| × 路径配比乘积 | Σ 根编码 \|净预测\| × 路径配比乘积 |
| 上游全无预测 | 需求 0（已知），照常计算 | **标数据不完整**（需求 null） | **标数据不完整**（根无预测） |

透传节点（passThrough）：图上保留（虚线灰边）、可在搜索栏搜到、自身不计缺口、不计入「数据不完整」KPI。需求来源（targets）的展示与数值规则一致：direct 显示直接父项，cross/top 显示上溯后的编码。

## 三、场景矩阵（实测输出）

场景均为 `A→B→C`，A=100、C=50、配比 1:1，除注明外。

### S1 全部有预测 · 同产业（B=80）
| 口径 | C 需求 | C 缺口 | 来源 |
|---|---|---|---|
| direct | 80 | 30 | B（直接父项） |
| cross | 100 | 50 | A（本产业最顶层） |
| top | 100 | 50 | A（最顶层） |

### S2 全部有预测 · C 属产业1、B/A 属产业2（B=80）
| 口径 | C 需求 | C 缺口 | 来源 |
|---|---|---|---|
| direct | 80 | 30 | B（直接父项） |
| cross | 80 | 30 | B（跨产业首个编码，边界停在 B） |
| top | 100 | 50 | A（最顶层） |

### S3 B 无预测 · 均在表6 · 同产业
| 口径 | C 需求 | C 缺口 | 来源 |
|---|---|---|---|
| direct | **0** | **-50（富余）** | B（预测按 0） |
| cross | 100 | 50 | A（跳过 B 上溯） |
| top | 100 | 50 | A |

### S4 B 无预测 · C 属产业1、B/A 属产业2（你确认的场景）
| 口径 | C 需求 | C 缺口 | 来源 |
|---|---|---|---|
| direct | 0 | -50 | B（直接父项，预测 0） |
| cross | 100 | 50 | A（跨产业首个编码） |
| top | 100 | 50 | A |

### S5 B 不在表6（无维护行）· 无预测 → 未知部门
与 S4 完全相同：direct 停 B（未知部门、预测 0）；cross/top 上溯到 A（100）。

### S6 B 在表6 但 make_dept 为空 · 无预测 → 未知部门
与 S4 完全相同。

### S7 整条上游都无预测（A、B 均无，C=50）
| 口径 | C 需求 | C 缺口 | 状态 |
|---|---|---|---|
| direct | 0 | -50 | 完整（父项按 0） |
| cross | null | null | **数据不完整** |
| top | null | null | **数据不完整**（根 A 无预测） |

### S8 多层连续无预测（A→B1→B2→C，B1/B2 无预测）
| 口径 | C 需求 | C 缺口 | 来源 |
|---|---|---|---|
| direct | 0 | -50 | B2（直接父项） |
| cross | 100 | 50 | A（连续跳过 B1/B2 上溯） |
| top | 100 | 50 | A |

### S9 双父项：B1=30 有预测；B2 无预测且其上游 D 也无预测
| 口径 | C 需求 | C 缺口 | 状态 |
|---|---|---|---|
| direct | 30（B1）+ 0（B2） | -20 | 完整 |
| cross | 30（按已知部分合计） | -20 | **部分来源数据缺失**（可计算，非整体不完整） |
| top | 30（已知根贡献合计） | -20 | 部分来源数据缺失 |

> 当前规则：跨产业与最顶层下「任一路径上游无预测但仍有其他已知贡献」时，按已知部分计算需求与缺口，并标注「部分来源数据缺失」；只有全部上游都无预测时才标为数据不完整。直接父子规则不变（停直接父项按 0 计）。

### S10 汇聚 DAG 与配比乘积（P1→M ×2，P2→M ×3，M→C ×1；P1=10、P2=20、C=5，M 无预测）
| 口径 | C 需求 | C 缺口 | 来源 |
|---|---|---|---|
| direct | 0（停 M） | -5 | M（直接父项） |
| cross | 10×2 + 20×3 = **80** | 75 | P1、P2（跳过 M 上溯到根） |
| top | 80 | 75 | P1、P2 |

### S11 B 显式预测 0（有记录，qty=0）· 跨产业（C 属 Y，B/A 属 X）
| 口径 | C 需求 | C 缺口 | 来源 |
|---|---|---|---|
| direct | 0 | -50 | B |
| cross | **0** | -50 | B（显式 0 = 有预测记录，停在边界 B，不再上溯 A） |
| top | 100 | 50 | A |

> 显式 0 与无记录的区别就在这里：显式 0 会「停住」，无记录会被跳过/按 0 透传。

## 四、展示与交互行为对照

| 行为 | 规则 |
|---|---|
| 网络图节点范围 | 全量 BOM；聚焦编码时只保留有向上游闭包 ∪ 有向下游闭包（兄弟/堂兄弟不进图） |
| 透传节点 | 虚线灰边；不计缺口；可搜索（部门显示「未知部门」）；详情页提示「无预测记录（透传）」 |
| 预测值为 0 的编码 | 显示设置可开关（默认显示）；透传节点始终保留以免断链 |
| 无关系边的独立节点 | 超过 100 编码默认隐藏，可在设置中改 |
| 箭头方向 | 顶层→底层（默认）/ 底层→顶层 可切换 |
| 配比标签 | ×N（默认）/ 1:N 可切换；≥100 节点默认隐藏，可手动开 |
| 缺口为负（富余） | 汇总表以结余口径展示：负数为缺口（红），正数为富余（绿） |
| 库存 | 表4 取当日最新快照（每日零点刷新一版），只计入起始月一次 |
