# 演示数据与单表模板

界面的「加载示例」和「下载完整示例Excel」统一使用：12个产业、10个加工地、240个编码、最多5层BOM。五层分别包含12、36、60、72、60个编码，保留11个月预测和库存，以及生产指令、加工周期、变异系数、共用下层、单一/多个加工地、供应不足和富余等展示场景。

数据生成入口为`server/demo-data.js`。在线构建任务、直接服务调用和示例Excel下载均使用同一生成器。原大规模压力测试数据生成器保留，不再用于界面的示例入口；未修改计算引擎或既有产物格式。

数据导入页面的六张表卡片都提供「下载模板（含3条样例）」：月度预测、BOM、库存、制造属性、供应添加/使用剔除、生产指令。独立模板只包含对应数据表和填写说明；「下载全部模板」包含全部六张表，每张3条样例。

接口：`GET /api/export?kind=template&table=forecast`。`table`可选`forecast`、`bom`、`inventory`、`attributes`、`adjust`、`mo`；省略时下载全部模板，非法表名返回400。

各模板使用相互匹配的`DEMO-001`～`DEMO-003`编码，方便合并为一批导入验证。正式使用前请替换样例；单独导入某张表不代表已具备完整分析数据。表2“使用”行的外购编码留空；已预处理净预测模式不再重复应用表2。

验证覆盖：示例实际规模、三种口径、导出后再导入、离线构建、六份单表模板合并构建、非法表名、HTTP下载，以及浏览器每张卡片实际下载的工作表与样例行数。

生效方式：重启服务并刷新页面；若当前已有旧示例数据，在数据管理中点击「加载示例」生成新版240编码示例。现有业务数据不会因代码更新自动替换。
